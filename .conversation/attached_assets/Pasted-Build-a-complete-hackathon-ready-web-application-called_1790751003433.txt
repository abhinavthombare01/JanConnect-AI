Build a complete hackathon-ready web application called **JanConnect AI**.

### PROJECT PURPOSE

JanConnect AI is a multilingual AI-powered civic-development intelligence platform for India.

The platform collects citizen infrastructure requests and complaints through text input, analyses them using AI, classifies the issue, estimates its priority, associates it with a location, and presents aggregated demand patterns on an administration dashboard.

The purpose is to help policymakers understand where citizens are requesting development and what types of infrastructure are most needed.

This is a **hackathon prototype**, not a production government system.

Do NOT build an unnecessarily complex enterprise system. Prioritize a polished, reliable, fast and visually impressive working MVP that can be demonstrated in 5–10 minutes.

---

# 1. CORE USER FLOW

The main flow should be:

Citizen enters complaint
→ AI analyses complaint
→ Category detected
→ Priority detected
→ Short summary generated
→ Location selected
→ Complaint stored
→ Dashboard updates
→ Map shows complaint location
→ Multiple nearby complaints create a visible hotspot
→ AI generates development recommendations
